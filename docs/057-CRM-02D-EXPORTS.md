# CRM-02D — خروجی گزارش‌های فیلترشده

**مجوز مالک:** ۲۰۲۶-۱۱-۲۷، آخرین قابلیت پیش از بازبینی و رفع Issueها. Issue #609.

- سه فهرست مشتریان مستقیم، نمایندگان و رکوردهای مشتریان نمایندگان (با گروه‌بندی موجود). داشبورد و صفحات جزئیات خارج از این فاز.
- همه فیلترها، مرتب‌سازی، گروه‌بندی و معیارهای RFM فعلی از همان ReadCrmDirectory؛ خروجی مستقل از شماره صفحه، حداکثر ۲۰۰۰ ردیف و ۲ MiB محتوای فایل. بیشتر از سقف رد می‌شود، نه خروجی ناقص.
- SuperAdminTrust در هر درخواست Livewire و Action؛ بدون مسیر دانلود عمومی، ذخیره فایل سمت سرور یا ارسال بیرونی. فایل با درخواست صریح کاربر ایجاد می‌شود.
- CSV با UTF-8 BOM، محافظت از formula injection و quoting استاندارد؛ JSON با نوع داده‌ها و ستون‌ها؛ Markdown با escape HTML و نویسه‌های ساختاری. نام ستون‌ها ثابت و قابل پردازش، مبلغ به ریال و تاریخ UTC؛ مقدار نامشخص JSON برابر null و CSV/Markdown خالی است.
- فقط ستون‌های allowlist گزارش: نام و شناسه حساب مشتری مستقیم/نماینده، شاخص‌های مشاهده‌شده و آمار تسویه؛ نام و شماره تماس مشتری زیرمجموعه نماینده، ایمیل، شناسه تلگرام، رمز و لینک اشتراک در خروجی نیستند. در رکورد تماس فقط وجود شماره ثبت می‌شود. هیچ متن جست‌وجو یا معیار حساس داخل فایل نیست.
- هیچ Migration، تغییر داده تجاری، وابستگی، پیام یا Provider call. فایل دانلودشده در اختیار مدیر است و باید محرمانه نگهداری شود.

## پذیرش
- [ ] CI: تطبیق فیلترها، گروه‌بندی، داده canonical، دسترسی، سقف، خروجی خالی، escape CSV/Markdown و دانلود واقعی Livewire.
- [ ] پس از استقرار: تطبیق نمونه گزارش واقعی در هر سه فرمت، زمان پاسخ، دانلود مرورگر و صحت مقادیر.
- پس از 02D توسعه قابلیت جدید تا بازبینی و رفع Issueها و تأیید مجدد مالک متوقف است.

## تغییرات کاربر
- دریافت خروجی نتایج فیلترشده مشتریان و نمایندگان در قالب CSV، JSON و Markdown.
